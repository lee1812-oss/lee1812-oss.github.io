📱 미니포스기 원격 설치 안내 (RustDesk)

준비 약 10분
1. 미니포스기 앞에서, 와이파이가 연결된 상태로 해요.
2. 막히면 조조에게 말해 주세요. 팀뷰어 QuickSupport로 화면을 보면서 도와드려요(현장에서 「허용」 한 번).
3. 비밀번호는 보관함 「RustDesk - 미니포스기」에 있어요.
1

설치 파일 받기

미니포스기의 인터넷(크롬)을 열고 아래 주소를 넣거나, 카메라가 있으면 QR을 찍어요.
lee1812-oss.github.io/pos/rdapk.html

⬇ 이 기기에서 바로 받기

받는 파일: RustDesk 1.5.3 안드로이드(모든 기기용, 약 75MB). 공식 GitHub에서 받아요.

2

설치하기

  1. 다운로드가 끝나면 알림이나 「다운로드」에서 파일을 눌러요.
  2. 「이 출처의 앱 설치 허용」이 나오면 설정 → 허용을 켜고 뒤로 와요.
  3. 설치 → 열기를 눌러요.
3

「제한된 설정 허용」 안드로이드 13 이상만

  1. 4번에서 접근성을 켜려는데 회색으로 막히면 이 단계를 해요.
  2. 설정 → 애플리케이션 → RustDesk → 오른쪽 위 ⋮ → 「제한된 설정 허용」을 눌러요.
  3. 화면 잠금 비밀번호를 물으면 넣어요.
4

화면 공유·조작 허락하기

  1. RustDesk 아래쪽 「화면 공유」 탭을 눌러요.
  2. 「서비스 시작」 → 「지금 시작」(화면 녹화 허락)을 눌러요.
  3. 「입력 제어」를 켜면 접근성 화면으로 가요. 설치된 앱(서비스) → RustDesk Input → 사용을 켜고 돌아와요.
  4. 「파일 전송」은 켜지 않아도 돼요.
5

고정 비밀번호 넣기

  1. 「화면 공유」 탭 오른쪽 위 ⋮ → 「영구 비밀번호 설정」을 눌러요.
  2. 보관함 「RustDesk - 미니포스기」 비밀번호를 두 칸에 똑같이 넣어요.
  3. 같은 메뉴에서 「영구 비밀번호 사용」을 골라요(일회용 비밀번호 끄기).
🔑 비밀번호는 사진·카톡으로 보내지 마세요. 보관함에서만 봐요.
6

켜질 때 자동 시작 · 꺼지지 않게

  1. RustDesk 「설정」에 「부팅 시 시작」이 보이면 켜요. 「다른 앱 위에 표시」를 물으면 허용해요.
  2. 설정 → 배터리 → RustDesk → 「제한 없음(최적화 안 함)」으로 해요.
  3. 주의안드로이드는 다시 켠 뒤 「서비스 시작」(화면 녹화 허락)을 한 번 더 눌러야 할 수 있어요.
7

ID 알려 주기 마지막

  1. 「화면 공유」 탭 위쪽의 ID 숫자(9~10자리)를 조조에게 알려 주세요.
  2. 조조가 원격 센터에 넣고 접속 시험을 해요.
